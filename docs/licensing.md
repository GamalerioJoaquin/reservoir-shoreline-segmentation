## This repository

## RiverScope

RiverScope's official documentation repository is marked CC0-1.0. That label
applies to the upstream repository's published materials, not automatically to
every satellite product bundled in the archive. The Zenodo record is the
authoritative source for the released archive and its current terms:

- Dataset record: <https://zenodo.org/records/15376394>
- Dataset repository and structure: <https://github.com/cvl-umass/riverscope>
- Dataset DOI: <https://doi.org/10.5281/zenodo.15376394>

The project does not commit or redistribute RiverScope files. In particular,
the normalized PlanetScope tiles, labels, co-registered products, and any raw
Planet-linked imagery remain external data. Before publishing, sharing, or
creating a derived dataset, check the current Zenodo terms, the RiverScope
repository license, and any applicable Planet imagery restrictions. Do not
assume that this repository's MIT license grants rights over those external
files.

## Attribution

When using RiverScope, cite the dataset and its associated publication as
listed by the authors in the official repository and Zenodo record.
